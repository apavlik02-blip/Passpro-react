# Fonts for the video bot

Drop these TTF files here to match the PassPro brand (all SIL Open Font License):

- `Fraunces.ttf` and `Fraunces-Italic.ttf` (variable fonts from github.com/google/fonts, `ofl/fraunces`)
- `Inter.ttf` (variable font from github.com/google/fonts, `ofl/inter`)
- `JetBrainsMono.ttf` (from github.com/google/fonts, `ofl/jetbrainsmono`)

If the files are missing, the bot falls back to DejaVu fonts.
